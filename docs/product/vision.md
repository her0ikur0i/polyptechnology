# Product vision

Polyp converts an owner's intent into secure, observable, verifiable software
delivery. The Master Dashboard is a control plane, not a generated project.

## Primary experiences

- Conversation workspace: discuss, attach context, design, and create contracts.
- Operations console: inspect, approve, pause, recover, and audit work.
- Factory Live View: a lightweight browser-rendered view of real orchestration.
- Knowledge workspace: curate reusable evidence, patterns, and blueprints.

## Generated projects

Projects are dynamic registry entries with independent repositories, secrets,
budgets, data, containers, deployments, and knowledge boundaries. Surachman
Center and Instalova are future generated projects, not control-plane modules.

## Non-goals for the first release

- Kubernetes, multi-node high availability, public plugin marketplace.
- Fine-tuning proprietary models or ML-based routing.
- Autonomous production/DNS mutation without human approval.
- Multi-organization billing and native mobile applications.
